Create the first V2 prototype around the highest-leverage surfaces only:
1. Navigation

## Step 2 — Review against V2 principles
Evaluate the prototype for:
- premium / boutique advisory feel
- Ainos brand distinctiveness

- desktop/mobile composition

## Step 3 — Production implementation
Only after the direction is coherent:

- extend browser visual QA
- keep source checks and production smoke green
